# 热点雷达展示规则

## 热度排行榜配色

- 橙色：A级热点，已通过业务相关性与风险审核，可结合业务借势。
- 黄色：B级热点，达到借势门槛并已通过业务相关性与风险审核，可结合业务借势。
- 灰色：仅监测或存档，不建议业务借势。

配色表达的是最终的“借势决策状态”，不能仅按事件题材或风险类型机械判断。排行榜、事件详情卡和业务建议必须保持一致。

### 台风等灾害类事件

灾害类事件默认从严评估，但不自动等同于灰色。若事件已经通过审核，并采用气象预警、民生保障、应急物资、履约提醒等服务型方案进行借势，应按其热点等级使用对应颜色。

当前案例：“台风沙德尔生成”已被确定为可借势的 B 级事件，因此排行榜柱子使用黄色；后续更新不得仅因其属于台风事件而改回灰色。
