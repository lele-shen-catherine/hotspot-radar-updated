# 外卖-业务理解+热点借势案例（来源：京me文档 wmBJHdW2DcmWv9QGJSQB）

## 借势方法论核心
1. **紧贴即时热点，以"轻量化内容"实现高频心智触达**
   - 针对天然无新闻点、重营销的"今日半价"，沉淀快速热点响应力 + 内容"短平快"生产能力
   - 借势《牛来》→手搓AI视频《饭来》；彩虹合唱团风格→AI视频"打工人续命计划"；借梗"V我10快点京东外卖"
   - "热点+IP"借势模式：低成本轻量创意撬动数倍互动 → 转化为对"今日半价"IP的关注 → B端商家主动咨询加入 → 形成"传播声势-商家信心-供给丰富-用户受益"良性循环

2. **深度协同业务，以"场景化沟通"激发共鸣与搜索转化**
   - 洞察"今日半价"客群 = 打工人 + 校园用户
   - 从打工人真实痛点出发，"打工人续命计划"创意，把"半价"拆解为职场具体场景
   - 小红书达人种草 + GEO问搜优化（如"工作餐在哪儿点划算"）+ "V我10块"玩梗
   - "打工人续命计划"长期落地到秒送频道toC会场

3. **可提升点**：单点爆发、借势随机性；需建"热点素材库"，响应从T+1提升至实时

## 关键IP与利益点
- 今日半价、超级月卡、周菜单、宝藏小馆、夜宵严选、自提奶茶、看球套餐
- 核心利益点：性价比/半价/10元吃饱、品质好送得快、订一周吃7天、场景化（打工人/学生党/宝妈/夜宵/七夕/看球）
