# 京东秒送（即时零售）业务理解+好案例（来源：京空间 NhiaLoXnAFIBiS5F5pEp）

## 行业竞争主线
过去3个月即时零售竞争主线：从"把订单做大"转向"把非餐供给、履约效率、用户心智、单位经济模型做深"。
- 淘宝闪购：整合盒马/天猫超市/前置仓，非餐规模下个财年将超餐饮；88VIP约6400万
- 美团闪购：以高频本地需求、夜间场景、药店网络、品牌门店+即时履约为抓手；小象超市68城、小黄灯24h药店1.6万家
- 京东秒送最值得抢的：不是复刻全品类补贴，而是把正品/品质/供应链/服务能力转化为"确定性"（时效/正品/库存/价格/售后可感知承诺），抢先经营高客单价高信任品类（3C、高化、白酒、家电、品质生鲜、应急）

## 品类策略：3+N
- 3：3C、高化、白酒
- N：品质应急（医药/母婴/宠物/护理/雨具）；高客单即时消费（手机电脑家电运动酒类高端礼赠）；品质家庭消费（生鲜乳品食品个护）；节点礼赠（七夕/生日/纪念日/毕业/乔迁/异地送礼）
- 强调"送到以后能不能放心使用"（正品/包装/验收/售后/复购）

## 供给与履约：品牌门店+自营秒送仓+本地商家混合网络

## 用户和传播（把"即时"讲成解决问题的服务）
- "临时要用，放心交给秒送"（真实应急场景）
- "好东西，现在就能到"（3C/家电/酒类/母婴/品质生鲜，正品与服务）
- "给重要的人，及时送到"（节日/异地/礼赠/家庭关怀，情绪价值+履约确定性）
